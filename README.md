# 🤖 AI Chatbot – Today Plan Generator

This is a simple AI chatbot built using Python.  
It interacts with users and generates a daily plan based on user input using basic NLP keyword matching.

## 🚀 Features
- Text-based AI chatbot
- Keyword matching (NLP basics)
- Generates a daily routine plan
- Runs on Google Colaboratory or local system
- Beginner-friendly AI project

## 🛠️ Technologies Used
- Python
- Google Colaboratory
- Basic NLP concepts

## ▶️ How to Run
1. Open Google Colab
2. Paste the code into a new notebook
3. Run the cell
4. Type: `make my today plan`
